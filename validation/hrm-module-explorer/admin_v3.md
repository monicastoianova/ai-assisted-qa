## Purpose (i)

The Admin module is the system-configuration center of OrangeHRM. It is where administrators manage system user accounts and access, define the lookup values used throughout the rest of the application (job titles, pay grades, employment statuses, qualifications, nationalities), configure the organization's structure and locations, and control application-wide settings such as email delivery, localization, enabled modules, branding, and external authentication (OAuth/LDAP/social login). Nothing here is day-to-day HR casework — it is the scaffolding other modules (PIM, Leave, Time, Recruitment, Performance) depend on.

## Business Context (i)

System administrators and IT/HR operations staff use this module infrequently but with high impact: a change here (e.g. adding a Job Title, disabling a module, misconfiguring LDAP) ripples across every user in the system. Most submodules follow the same "reference data" pattern — a searchable/sortable list with Add, Edit, and Delete actions — used to keep dropdown values elsewhere in OrangeHRM (e.g. Job Title on an employee record) consistent and centrally managed. The Configuration section additionally controls integration and infrastructure concerns (mail transport, LDAP sync, OAuth clients) that are typically owned by IT rather than HR.

## Relationships to Other Modules (i)

- **PIM** — Job Titles, Pay Grades, Employment Status, Job Categories, Nationalities, and Qualifications (Skills/Education/Licenses/Languages/Memberships) defined in Admin populate dropdowns on employee PIM records.
- **My Info** — The same qualification and nationality reference lists appear on the employee-facing My Info tabs.
- **Time** — Work Shifts defined in Admin are used for time/attendance scheduling.
- **Leave** — Employment Status and organizational Structure/Locations affect leave eligibility and approval routing.
- **Recruitment / Performance / Directory / Maintenance / Claim / Buzz** — Each can be globally enabled or disabled via Configuration → Modules.
- **All modules** — Corporate Branding, Localization, and Email Configuration affect the visual theme, language/date formatting, and notification delivery across every module.
