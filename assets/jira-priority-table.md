## Priority table (use exact Jira labels)

| Priority | When to apply |
|----------|---------------|
| Highest  | System crash, data loss, security breach, blocks all users |
| High     | Core feature broken, no workaround available |
| Medium   | Feature works but incorrectly, workaround exists |
| Low      | Cosmetic issue, minor UX problem, affects few users |
| Lowest   | Typos, minor text/alignment, purely aesthetic, no functional impact |
