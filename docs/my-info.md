# OrangeHRM — My Info Module

> Auto-generated by the `hrm-module-explorer` skill on 2026-06-17

## Purpose

The My Info module gives every employee self-service access to their own HR record. Employees can view and update personal data, contact information, qualifications, and other profile sections without contacting HR — reducing administrative overhead while keeping records accurate and up to date.

## Business Context

HR teams configure what employees can edit (e.g., personal details, emergency contacts, qualifications) while keeping sensitive data like salary and job classification read-only for the employee. This separation of concerns allows organisations to maintain data integrity in payroll and workforce planning while still empowering employees to keep their own profiles current. The module surfaces the same underlying record as the PIM (People Information Management) module but scoped to the logged-in user only.

## Tabs / Features

### Personal Details
**What it does:** Stores the employee's core identity and demographic information.
**Who uses it:** Employee (self-update); HR Admin (via PIM).
**Key fields / actions:**
- Employee Full Name (First Name, Middle Name, Last Name) — required
- Employee Id, Other Id
- Driver's License Number, License Expiry Date
- Nationality (dropdown), Marital Status (dropdown)
- Date of Birth, Gender (Male / Female)
- **Custom Fields** subsection: Blood Type (dropdown), configurable text fields (e.g. Test_Field)
- **Attachments** table (File Name, Description, Size, Type, Date Added, Added By) — Add / Edit / Delete / Download actions

### Contact Details
**What it does:** Captures the employee's home and work contact information.
**Who uses it:** Employee (self-update); HR Admin.
**Key fields / actions:**
- **Address:** Street 1, Street 2, City, State/Province, Zip/Postal Code, Country
- **Telephone:** Home, Mobile, Work
- **Email:** Work Email, Other Email
- Save button; Attachments table

### Emergency Contacts
**What it does:** Maintains a list of people to contact in case of an emergency involving the employee.
**Who uses it:** Employee (self-update); HR Admin.
**Key fields / actions:**
- **Assigned Emergency Contacts** table: Name, Relationship, Home Telephone, Mobile, Work Telephone, Actions
- Add / Edit / Delete actions on each record
- Attachments table

### Dependents
**What it does:** Records family members or other dependents associated with the employee, typically used for benefits administration.
**Who uses it:** Employee (self-update); HR Admin / Benefits teams.
**Key fields / actions:**
- **Assigned Dependents** table: Name, Relationship, Date of Birth, Actions
- Add / Edit / Delete actions
- Attachments table

### Immigration
**What it does:** Tracks travel documents (passports, visas, work permits) and their validity periods to support compliance and travel approvals.

**Key fields / actions:**

### Job
**What it does:** Displays the employee's current job classification and assignment. This tab is **read-only** for the employee.
**Who uses it:** Employee (view only); HR Admin manages data via PIM.
**Key fields / actions:**
- Joined Date (read-only), Job Title, Job Specification
- Job Category, Sub Unit, Location, Employment Status
- Checkbox: Include Employment Contract Details
- Attachments table (read-only for employee)

### Salary
**What it does:** Shows the employee's salary components. This tab is **read-only** for the employee.
**Who uses it:** Employee (view only); HR / Payroll admin manages data via PIM.
**Key fields / actions:**
- **Assigned Salary Components** table: Salary Component, Amount, Currency, Pay Frequency, Direct Deposit Amount

### Report-to

**Who uses it:** Employee (view only); HR Admin manages data via PIM.

### Qualifications

### Memberships

## Relationships to Other Modules

- **PIM** — My Info is a scoped view of the employee's PIM record; HR Admins manage the same data fields via PIM > Employee List.
- **Leave** — Employment status and start date (from the Job tab) affect leave entitlement calculations.
- **Time** — Sub Unit and Location (from the Job tab) are referenced in timesheets and project assignments.
- **Performance** — The Report-to hierarchy (supervisors/subordinates) drives the performance review chain.
- **Recruitment** — Qualifications data can be compared against job requirement profiles during internal hiring.
- **Admin** — Custom Fields (e.g. Blood Type, Test_Field on Personal Details) are configured by Administrators under PIM Configuration.
